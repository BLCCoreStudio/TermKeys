# Contributing to TermKeys

Thank you for your interest in improving TermKeys.

TermKeys uses a split development model:

- the complete implementation is proprietary and maintained privately by BLCCoreStudio
- this public repository contains documentation, contribution resources, release information, and other intentionally published material

Contributing to this repository does not provide access to the private TermKeys development repository.

## Contributions We Welcome

Community contributions may include:

- documentation improvements
- typo and wording fixes
- English and Turkish translations
- usage examples
- compatibility reports
- bug reports
- feature requests
- usability suggestions

## Private Implementation

The following areas are maintained privately by BLCCoreStudio:

- application source code
- configuration management implementation
- backup and restore implementation
- conflict detection logic
- internal tests
- build tooling
- release engineering
- proprietary product logic

## Pull Requests

Before submitting a pull request:

1. Keep the change focused.
2. Explain what the change improves.
3. Do not include credentials, secrets, private keys, or private repository content.
4. Do not add executable binaries unless explicitly requested by BLCCoreStudio.
5. Do not add executable scripts or dependencies without prior discussion.
6. Review your diff before submitting.

All pull requests are reviewed before merging.

Submitting a pull request does not guarantee acceptance.

## Security

Do not report suspected security vulnerabilities through public issues.

Follow `SECURITY.md`.

Never publish:

- passwords
- API keys
- access tokens
- SSH keys
- private keys
- confidential configuration
- private repository data

## Malicious Contributions

Contributions containing any of the following will be rejected:

- malware
- backdoors
- credential theft
- destructive filesystem behavior
- unauthorized telemetry
- unexpected network communication
- obfuscated malicious behavior
- supply-chain attacks
- attempts to weaken TermKeys security controls

## Licensing

By submitting a contribution, you confirm that you have the right to provide it.

Accepted public contributions become part of the public TermKeys repository under its applicable licensing terms.

Public contribution does not grant access to or rights over the proprietary TermKeys implementation.
