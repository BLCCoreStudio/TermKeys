# Changelog

All notable changes to TermKeys will be documented in this file.

## [0.1.0] - 2026-08-27

### Added

- Initial Linux x86_64 release
- Fish shell F12 quick-clear integration
- GNU Nano F12 buffer-clear integration
- Automatic original configuration backup
- Safe restore workflow
- Safe uninstall
- Existing F12 conflict detection
- Managed configuration ownership checks
- Atomic configuration writes
- Existing file permission preservation
- Restore path validation
- `status` command
- `doctor` command
- `plan` command
- SHA-256 release verification
- Proprietary binary distribution model

### Security

- No sudo requirement
- No telemetry
- No intentional network communication
- No credential storage
- Refuses unsafe configuration overwrites
